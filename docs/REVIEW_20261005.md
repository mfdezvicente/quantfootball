## Comandos para continuar

Desde la raíz del repositorio, obtener nuevas capturas públicas cuando los
partidos hayan terminado. Elegir una carpeta de captura nueva y una fecha de
corte no posterior al día real en Madrid. Por ejemplo, ejecutar estos comandos
el 6 de octubre o después:

```powershell
python scripts/capture_current_results.py --competition es.2 --year 2026 --matchday 8 --output-dir data/raw/review_20261006
python scripts/refresh_dataset.py --base data/processed/matches_quiniela_20261005.parquet --snapshot data/raw/review_20261006 --as-of 2026-10-06 --output data/processed/matches_quiniela_20261006.parquet
python scripts/probability_registry.py evaluate --dataset data/processed/matches_quiniela_20261006.parquet --output outputs/reports/j11_review_20261006/probability_evaluation.json
python scripts/evaluate_market_studies.py --root outputs/predictions/market_matches --dataset data/processed/matches_quiniela_20261006.parquet --output outputs/reports/j11_review_20261006/market_evaluation.json
python scripts/review_predictions.py --record outputs/predictions/probability_pairs/2026_j11 --dataset data/processed/matches_quiniela_20261006.parquet --probability-evaluation outputs/reports/j11_review_20261006/probability_evaluation.json --market-evaluation outputs/reports/j11_review_20261006/market_evaluation.json --output-dir outputs/reports/j11_portfolios_20261006
python scripts/forecast_registry.py summary
```

La carpeta de captura debe contener los JSON originales de jornadas de LaLiga;
para otras jornadas usar `--competition es.1`, `es.2` o `es.w.1` y su número
de jornada; `--matchday` se puede repetir. No se sustituye el histórico con el que
ya se generó J12. El siguiente modelo que incorpore cuotas, alineaciones o
porcentajes del público deberá tener una versión y un protocolo anteriores
a sus propios resultados.
