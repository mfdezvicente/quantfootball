Reproducción

Ejecutar desde la raíz del repositorio con el entorno instalado y rutas de salida nuevas.

python scripts/context_challenger.py replay --dataset data/processed/matches_quiniela_20261124.parquet --protocol configs/context_challenger_protocol_20261124.json --end 2026-11-24 --output outputs/reports/context_replay_replica
python scripts/compare_diversified_columns.py --output outputs/reports/portfolio_comparison_replica.json

El subcomando evaluate del experimento de calibración cruza el directorio de pronósticos sellados con un snapshot de resultados finalizados. El estudio mantiene la estrategia económica en simulación.
